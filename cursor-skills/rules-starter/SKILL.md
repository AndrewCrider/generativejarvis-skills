# Rules Starter

Generate a personalized `.cursorrules` file and universal AI system prompt from 6 questions.

---

## Required inputs (ask one at a time)

1. **What do you do for work?** (Role, industry, freelancer/founder/employee. More specific = better output.)

2. **What are your 3 most active projects right now?** (Name + one-sentence description each. Include deadline if there is one.)

3. **What is the #1 recurring task you do every week that AI could help with?**

4. **How do you prefer to communicate?** (Pick all that apply: Direct / Diplomatic / Formal / Casual / Technical / Plain / Brief / Thorough)

5. **Do you know your MBTI type?** (If yes, tell me. If not, skip — I'll add a placeholder.)

6. **What's your biggest AI frustration?** (Pick one: It doesn't know my context / Output too generic / Can't stay consistent / Can't match my voice / Wastes my time with questions / Other)

---

## Output contract

Generate both outputs below. Use their actual answers — no generic placeholders where you have real data.

### Output 1: `.cursorrules` file

```
# [Role/Name]'s AI Rules
# Generated by Generate Jarvis Skills — generativejarvis.com
# Last updated: [today's date]

## Who I am
[1–2 sentences from Q1: role, industry, context]

## My active projects
[Q2: 3 projects, one line each]

## My recurring focus
My most time-consuming recurring task is: [Q3]. Prioritize accuracy and consistency over creativity for this.

## My communication style
[Map Q4 answers to 2–3 sentences:]
- Direct + Brief → "Lead with the answer. No filler. Reasoning only if I ask."
- Thorough + Technical → "Give me the full picture with reasoning. No summaries."
- Casual + Plain → "Talk like a smart colleague, not a press release."
- Formal + Diplomatic → "Professional tone. Constructive framing. No contractions."

## My personality
[If Q5 provided: "I am an [MBTI]. [1–2 sentence implication from MBTI mapping below.]"]
[If skipped: "MBTI: [fill in your type here]. This calibrates advice and pacing."]

## My biggest AI frustration
[Map Q6 to a behavioral rule:]
- Doesn't know context → "Never ask me to re-explain what project I'm working on. Read context above."
- Too generic → "Avoid boilerplate. If you can't be specific to my situation, say so."
- Inconsistent → "When I reference a prior decision, honor it. Don't re-litigate settled things."
- Can't match voice → "Read my communication style above before generating any content for me."
- Wastes time with questions → "Minimize clarifying questions. Make a reasonable assumption, state it, proceed."

## General rules
- Read this file before every response.
- Don't pad responses. My time is valuable.
- When uncertain, say so — don't hallucinate.
- Drafts should be usable, not structural skeletons I have to fill in.
```

### Output 2: Universal system prompt (ChatGPT / Claude / Gemini)

```
You are my personal AI assistant. Context before responding:

WHO I AM: [Q1 — role and context]
MY ACTIVE PROJECTS: [Q2 — 3 projects with descriptions]
MY RECURRING PRIORITY: [Q3 — most time-consuming task]
MY COMMUNICATION STYLE: [Q4 — 1–2 sentence style guide]
MY PERSONALITY: [Q5 if given — MBTI + 1 implication | placeholder if skipped]
IMPORTANT: [Q6 mapped to one behavioral rule, second person: "Do not..." or "Always..."]

Never ask me to re-explain context already in this prompt. When in doubt, make a reasonable assumption and state it.
```

## Usage instructions (always include)

**Cursor users:**
1. Create `.cursorrules` in your project root (or main workspace folder).
2. Paste the generated content.
3. Cursor reads it automatically at the start of every conversation.

**ChatGPT:** Settings → Personalization → Custom Instructions → paste in "What would you like ChatGPT to know about you?"

**Claude:** Start a Project → Project Instructions → paste.

**Gemini:** Gems → Create a Gem → paste as the system instruction.
