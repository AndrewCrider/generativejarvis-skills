## Installation

### Claude Code (recommended)

```bash
git clone https://github.com/AndrewCrider/generativejarvis-skills.git ~/.claude/plugins/generate-jarvis-skills
```

Then in Claude Code:

```
/plugin install ~/.claude/plugins/generate-jarvis-skills
```

### Cursor

Copy the contents of `cursor-skills/` into your project's `.cursor/skills/` folder.

Each subfolder (`ai-os-audit/`, `saboteur-scan/`, etc.) contains a `SKILL.md` file. Cursor will automatically detect them.
